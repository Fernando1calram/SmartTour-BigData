# SmartTour Big Data

Proyecto académico de análisis Big Data aplicado al turismo.

## Objetivo

Desarrollo de una plataforma Big Data para analizar información turística y crear cuadros de mando.

## Tecnologías

- Python
- Docker
- JupyterLab
- GitHub

## Estructura

datasets:
Datos utilizados en el proyecto.

scripts:
Programas Python.

notebooks:
Análisis realizados.

docs:
Documentación.
